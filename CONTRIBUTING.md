# Contributing

Thank you for your interest in improving SD Plotter DB.

Because this project is identified as registered software and currently uses an All Rights Reserved license, open contributions should be coordinated with the author before code is reused, redistributed or merged.

## Suggested contribution workflow

1. Open an issue describing the change.
2. Explain whether the change affects Processing desktop software, Arduino firmware, database/export behavior, hardware pinout or documentation.
3. Create a branch with a clear name.
4. Keep changes focused.
5. Test the change in demo mode first.
6. Test with safe bench hardware before real equipment.
7. Update documentation when behavior changes.

## Pull request checklist

- [ ] Processing source still runs.
- [ ] Arduino firmware still compiles.
- [ ] No local database, CSV, credentials, license keys or machine-specific files are committed.
- [ ] Documentation is updated.
- [ ] Safety implications are described.
