# Project Structure

This repository has been organized to make the project easier to publish and maintain on GitHub.

## Root files

| File | Purpose |
| --- | --- |
| `README.md` | Main public project page. |
| `LICENSE` | Conservative All Rights Reserved license placeholder. |
| `NOTICE.md` | Authorship, registration and third-party notices. |
| `CHANGELOG.md` | Version history. |
| `CONTRIBUTING.md` | Contribution guidelines. |
| `SECURITY.md` | Security and safety reporting notes. |
| `.gitignore` | Files that should not be committed. |
