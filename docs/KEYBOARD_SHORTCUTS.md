# Keyboard Shortcuts

SD Plotter DB includes keyboard shortcuts for fast operation. Shortcuts can be enabled or disabled through the **FN KEY** setting.

## Login window

| Key | Action |
| --- | --- |
| `ESC` | Cancel the action. |
| `ENTER` | Press the **OK** button. |
| `LEFT` / `RIGHT` | Same as `UP` / `DOWN`; scroll through user names in deletion mode. |
| `F1` | Open manual. |
| `F2` | Configure Windows authentication in creation mode. |
| `F3` | Enable or disable administrator configuration for a user in creation mode. |
| `F12` | Switch between user creation and deletion tabs. |

## Analysis window

| Key | Action |
| --- | --- |
| `ESC` | Disconnect if connected and not recording method/data or playing a method. |
| `ENTER` | Connect through serial communication. |
| `UP` / `DOWN` | Increase or reduce the time-rate value for data recording. |
| `LEFT` / `RIGHT` | Increase or reduce the sample-rate value of the line chart. |
| `PAGE UP` / `PAGE DOWN` | Move through the serial-port list. |
| `ALT` + `0` | Switch communication between LAN and Serial. |
| `ALT` + `1` to `ALT` + `8` | Enable or disable probe preview. |
| `HOME` | Take a snapshot. |
| `F1` | Open manual. |
| `F2` | Start recording analysis data. |
| `F3` | Start method reproduction. |
| `F4` | Start recording method. |
| `F5` | Perform login or enable EEPROM recording mode. |
| `F6` | Open database screen. |
| `F7` | Open settings screen. |
| `F8` | Open control screen. |
| `F9` | Normalize graphical scale or enable firmware recording mode. |
| `F10` | Update list of serial ports. |
| `F11` | Enable or disable monitor. |
| `F12` | Switch between Analysis and Display tabs. |

## Display window

| Key | Action |
| --- | --- |
| `SPACE` | Auto-scale the active graph. |
| `ALT` + `1` to `ALT` + `8` | Choose the graph to be displayed. |
| `UP` / `DOWN` | Increase or reduce the graph scale on the Y axis while maintaining the X axis scale. |
| `LEFT` / `RIGHT` | Move the graph forward or backward. |
| `HOME` | Take a snapshot. |
| `PAGE UP` / `PAGE DOWN` | Move through the displayed-data list. |
| `F1` | Open manual. |
| `F2` | Export data in `.CSV` format. |
| `F12` | Switch between Analysis and Display tabs. |

## Database window

| Key | Action |
| --- | --- |
| `ENTER` | Open files. |
| `DELETE` | Delete files. |
| `UP` / `DOWN` | Move through the file list for each tab. |
| `F1` | Open manual. |
| `F2` | Start the database. |
| `F3` | Generate database export. |
| `F5` | Open the Tables tab. |
| `F6` | Open the Methods tab. |
| `F7` | Open the Others tab. |
| `F8` | Open the Log tab. |

## Settings window

| Key | Action |
| --- | --- |
| `F1` | Open manual. |
| `F2` | Write firmware or erase EEPROM. |
| `F3` | Change communication input through serial or USB port. |
| `F4` | Open manager screen. |
| `F5` | Run signal demonstration. |
| `F6` | Run calibration mode. |
| `F7` | Activate or deactivate special key commands. |
| `F8` | Activate or deactivate data recording and method reproduction by external command. |
| `F9` | Use parameters recorded by Arduino or software. |
| `F10` | Enable or disable data smoothing. |
| `F11` | Enable or disable PID control for temperature. |
| `F12` | Enable or disable PID control for speed. |

## Control window

| Key | Action |
| --- | --- |
| `LEFT` / `RIGHT` | Change Probe 6 controls. |
| `UP` / `DOWN` | Change motor speed. |
| `F1` | Open manual. |
| `F2` | Start recording analysis data. |
| `F3` | Start method reproduction. |
| `F4` | Start recording method. |
| `F5` | Enable or disable Relay 1. |
| `F6` | Enable or disable Relay 2. |
| `F7` | Enable or disable Digital OUT 1. |
| `F8` | Enable or disable Digital OUT 2. |
| `F12` | Switch between Control and Preview tabs. |

## Preview window

| Key | Action |
| --- | --- |
| `ENTER` | Enable or disable graph visualization in logarithmic format. |
| `PAGE UP` / `PAGE DOWN` | Move through the displayed-method list. |
| `F1` | Open manual. |
| `F12` | Switch between Control and Preview tabs. |

## Text paste shortcut

| Key | Action |
| --- | --- |
| `ALT` + `V` | Paste text into a software field. |
