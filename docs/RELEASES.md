## Recommended GitHub release assets

When publishing a GitHub release, attach:

- Windows installer or compiled `.exe`.
- Source code ZIP.
- Arduino firmware ZIP for serial operation.
- Arduino firmware ZIP for Ethernet operation.
- Instruction manual.
- Checksums for compiled files.
